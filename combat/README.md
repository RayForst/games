# Бойцовский клуб — мобильный клон combats.ru

Пошаговый PvP-файтинг в духе старого «Бойцовского клуба»: 5 зон удара, 4 блока,
криты, увороты, броня, шмот, уровни. Сейчас это одиночный MVP против ботов,
полностью офлайн, с сохранением прогресса на телефоне.

Стек: **Expo SDK 57 + React Native + TypeScript + Expo Router + zustand**.
Никаких нативных модулей сверх того, что есть в Expo Go — проект запускается на iPhone без Mac и Xcode.

## Запуск на iPhone за 3 минуты

1. Поставь на iPhone приложение **Expo Go** из App Store.
2. На компьютере (в той же Wi-Fi сети):

   ```bash
   cd combat
   npm install
   npx expo start
   ```

3. Отсканируй QR-код камерой iPhone — откроется Expo Go с игрой.
   Каждое сохранение файла обновляет игру на телефоне за секунду.

Если телефон и компьютер в разных сетях: `npx expo start --tunnel`.

## Механика (коротко)

Все формулы в одном месте — `src/game/formulas.ts`.

- **Характеристики**: сила → урон, ловкость → уворот и антикрит, интуиция → крит и антиуворот, выносливость → hp.
  Старт 3/3/3/3 + 3 очка. За уровень +3 очка.
- **hp** = 12 + выносливость × 6 + уровень × 2 + бонусы предметов. Полная регенерация за 8 минут реального времени.
- **Урон** = урон оружия + сила (min +½ силы, max +сила). Кулаки 1–3.
- **Раунд**: оба одновременно выбирают зону удара (голова / корпус / живот / пояс / ноги) и блок (две соседние зоны).
  Порядок проверок: блок → крит сквозь блок (½ шанса крита) → уворот → крит → обычный удар.
- **Шанс крита** = 4 + крит атакующего − антикрит защищающегося, в коридоре 2…60 %. Уворот аналогично.
- **Крит** удваивает урон и игнорирует половину брони. Обычный удар режется бронёй зоны, минимум 1.
- **Ничья**, если оба падают в одном раунде.
- **Кольца и амулеты**: два слота колец и один амулета, одинаковые кольца можно. Бонусов к броне не дают — только
  характеристики, hp, крит/антикрит, уворот/антиуворот. Заточке не подлежат, изнашиваются как всё остальное.
- **Двуручное оружие** (Оглобля, Секира, Двуручный меч, Бердыш, Кувалда, Алебарда): урон примерно на треть выше
  одноручного того же уровня, минус 2–4 % к увороту. Вместе со щитом не носится: при надевании двуручника щит
  снимается в рюкзак, при надевании щита — двуручник. Боты живут по тому же правилу.
- **Стороны и расы** (`src/game/races.ts`): при создании выбираешь сторону и расу, раса даёт +1 к характеристике и черту
  (накладывается в `deriveStats` после умений). Перебежчик у князя: первый переход бесплатно, дальше 500 кр., +1 переезжает.

  | Сторона | Раса | +1 | Черта |
  | --- | --- | --- | --- |
  | Корона | Люди | сила | +10 % опыта за бой |
  | Корона | Карлы | выносливость | +4 кр./ч в шахте |
  | Корона | Полукровки | ловкость | регенерация ×1.25 |
  | Вольница | Степняки | интуиция | +3 % уворота |
  | Вольница | Орки | сила | +1 брони корпуса и пояса |
  | Вольница | Болотники | выносливость | травмы вдвое короче |

- **Война сторон** (`src/game/war.ts`): дневной счёт Корона : Вольница. Победа игрока над чужой стороной +3 очка своим
  и +2 рейтинга, поражение +3 чужим; местные дерутся сами (бой каждые 15 минут, по очку). Победитель вчерашнего дня
  сегодня получает ×1.1 кредитов за бои. Боты, именные соперники и гильдии местных имеют сторону; гильдия берёт только своих.
- **Боты** получают столько же очков характеристик, сколько игрок того же уровня, и шмот не выше своего уровня;
  требования вещей считают с учётом надетого, как игрок, и берут лучшее из доступного своему уровню.
  Чем выше уровень бота, тем чаще он закрывает зону, в которую ты бил чаще всего, и бьёт туда, что ты не блокировал.
- **Награда**: победа 12 + 14 × уровень соперника опыта и 6 + 10 × уровень кредитов (+0…4; ×1.3 за каждый уровень
  разницы), ничья половина, поражение 15 % опыта и ничего. Полный комплект своего уровня стоит около 55–65 боёв.
- **Баланс** проверяется симуляцией `npm run balance` (три архетипа, щит против двуручника, Город и Брод, все источники
  дохода). Цели и замеры — раздел «Баланс» в `ROADMAP.md`.

```
combat/
  src/app/              маршруты Expo Router (каждый файл — экран)
    _layout.tsx         корневой Stack, загрузка сохранения, регенерация hp

    types.ts            зоны, блоки, слоты, типы персонажа и боя
    items.ts            каталог предметов
    formulas.ts         все формулы баланса
    combat.ts           разрешение удара и раунда, тексты лога
    ai.ts               ход бота
    opponents.ts        генерация соперников
    leveling.ts         таблица уровней и награды
    character.ts        создание, экипировка, регенерация
  src/store/useGame.ts  zustand-стор + persist в AsyncStorage
  src/components/       UI-кирпичи (ZonePicker, FightLog, ItemCard, PaperDoll, Avatar…)
  src/ui/theme.ts       цвета, отступы, шрифты
```

## Потестить с телефона без компьютера

**Веб-версия на GitHub Pages** (без аккаунтов, обновляется сама при каждом пуше в ветку):

https://rayforst.github.io/games/

Открой в Safari на iPhone, через «Поделиться → На экран „Домой“» ярлык будет выглядеть как приложение.
Прогресс хранится в localStorage браузера. Сборку делает `.github/workflows/deploy-web.yml`;
один раз нужно включить Pages руками: Settings → Pages → Build and deployment → Source: «GitHub Actions»,
после этого запустить workflow заново (Actions → Deploy web to GitHub Pages → Re-run jobs).
Отличие от нативной версии: нет вибрации и системных диалогов подтверждения.

**Нативная версия в Expo Go через EAS Update** (нужен бесплатный аккаунт expo.dev, Apple-аккаунт не нужен):

```bash
cd combat
npx eas-cli@latest login
npx eas-cli@latest update:configure      # добавит expo-updates и projectId в app.json
npx eas-cli@latest update --branch preview --message "первая сборка"
```

После публикации на странице обновления в https://expo.dev появится QR-код «Open in Expo Go».
Один раз отсканировал, дальше проект лежит в Expo Go во вкладке проектов и открывается где угодно.
Каждый новый `eas update` подтягивается при следующем запуске.

**TestFlight** — как настоящее приложение, но нужен Apple Developer Program (99 $/год):

```bash
npx eas-cli@latest build -p ios --profile production
npx eas-cli@latest submit -p ios
```

Дальше в App Store Connect → TestFlight добавь себя тестировщиком и поставь приложение TestFlight на iPhone.

## Публикация в App Store

Mac не нужен — сборку и отправку делает облако EAS.

1. Аккаунт [Apple Developer Program](https://developer.apple.com/programs/) (99 $/год) — без него продавать нельзя.
2. Аккаунт [expo.dev](https://expo.dev) (бесплатный тариф хватит).
3. В папке `combat`:

   ```bash
   npx eas-cli@latest login
   npx eas-cli@latest build:configure     # привяжет проект, добавит projectId в app.json
   npx eas-cli@latest build -p ios --profile production
   npx eas-cli@latest submit -p ios       # отправит сборку в App Store Connect
   ```

4. В App Store Connect: скриншоты, описание, цена или встроенные покупки, отправка на ревью.

`bundleIdentifier` сейчас `com.rayforst.combat` — поменяй в `app.json`, если нужен другой.
Иконка и сплэш лежат в `assets/` (сейчас стандартные Expo — стоит заменить).

Иконки для предметов без своей картинки, ресурсов и карты мира — Game Icons (CC BY 3.0), см. `CREDITS.md`.
