# games

[![CI](https://github.com/RayForst/games/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/RayForst/games/actions/workflows/ci.yml)

Мобильные игры на Expo / React Native.

| Папка | Игра | Статус |
| --- | --- | --- |
| [`combat/`](./combat) | Бойцовский клуб — клон combats.ru, пошаговые бои по зонам | MVP, офлайн против ботов |

Запуск любой игры: `cd <папка> && npm install && npx expo start`, затем открыть в Expo Go на телефоне.
