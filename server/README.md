# server — сервер «Бойцовского клуба»

Чат, гильдии и роли для игры из `combat/`. Node 22 + TypeScript, WebSocket (`ws`) и немного HTTP,
состояние — один JSON-файл на диске. Базы нет нарочно: поднимается одной командой.

Правила игры сервер не копирует, а импортирует из `combat/src/game/` (`guild.ts`, `chat.ts`, `roles.ts`):
чистый TypeScript без React, одни формулы на телефон и сервер. Протокол — `combat/src/net/protocol.ts`,
контракт — `combat/src/net/backend.ts`, клиентский адаптер — `combat/src/net/serverBackend.ts`.

## Запуск

```bash
cd server
npm install
ADMIN_SECRET=ключник npm run dev      # tsx watch: перезапуск при правках
# или
npm start                              # без перезапуска
```

Проверка: `curl http://localhost:8787/health` → `{"ok":true,"users":0,...}`.

Телефон/браузер подключается, если при запуске Metro задан адрес сервера:

```bash
cd combat
EXPO_PUBLIC_BACKEND_URL=ws://192.168.1.10:8787 npx expo start
```

Пусто — игра работает как раньше, офлайн: чат с местными, гильдии местных, роль из сейва.
`EXPO_PUBLIC_*` вшивается в бандл на сборке, поэтому смена режима — перезапуск Metro.
Для своей сборки можно задать `EXPO_PUBLIC_ADMIN_SECRET`: телефон пошлёт его при входе.

## Переменные окружения

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `PORT` | `8787` | Порт HTTP и WebSocket (один на оба). |
| `ADMIN_SECRET` | пусто | Слово ключника. **Первый**, кто войдёт с ним, станет админом; дальше роли раздаёт он (`auth.assignRole`). Пусто — админа не будет. |
| `DATA_FILE` | `data/state.json` | Файл состояния: пользователи, лента, гильдии, заявки. Пишется с задержкой 200 мс, атомарно (tmp + rename). |

Шаблон — `.env.example`. Сам файл состояния в git не попадает (`data/*.json` в `.gitignore`).

## Что умеет

- **Вход** — `auth.hello { token, name, level, rating, adminSecret? }`. Токен устройства — случайная строка,
  телефон хранит её в AsyncStorage (`combat/src/net/device.ts`), сервер — только sha256. Имя уникально
  без учёта регистра; переименование персонажа переименовывает и в гильдии. Уровень и рейтинг сервер
  **не проверяет** (PvP-сервера с боями нет), они нужны для `joinCheck` при заявке в гильдию.
- **Роли** `player | moderator | gm | admin` живут на сервере. Права — `can(role, permission)` из `roles.ts`,
  те же, что в игре. Смена роли прилетает пользователю событием `me`.
- **Чат** — каналы `tavern`, `arena` (общие) и `guild` (своя лента у каждой гильдии, чужие не слышат).
  Лента каждого стола — до 200 сообщений (`CHAT_LIMIT`), текст чистится `cleanText`, до 240 знаков.
  Модерация (`chat.moderate`): удалить (игроки не видят, смотрящие видят зачёркнутым), заткнуть на N минут
  (0 — вернуть голос; нельзя затыкать равного или старшего по роли). Слово мира (`chat.broadcast`) — системное
  сообщение от автора `world` в любой канал.
- **Гильдии** — основать (с 3 уровня; имя, тег, герб проверяются как в игре), заявка (`guilds.apply`),
  приём/приглашение (`guilds.invite`, глава и десятники; заявки — `guilds.applications`), уйти, распустить
  (только глава), выгнать (десятника — только глава), ранги (глава), казна (`donate`; кредиты списывает
  телефон), уровень (`upgrade`, цена `guildLevelCost`), правка мастером (`guilds.edit`, `guild.manageAny`).
  События `guild.updated` уходят членам, `guild.ladder` — всем.
- **HTTP**: `GET /health`, `GET /history/tavern?limit=50`, `GET /history/arena` (без удалённых, без входа).

## Протокол

Одна JSON-строка на сообщение.

```jsonc
// клиент → сервер
{ "id": 1, "method": "auth.hello", "params": { "token": "dev-…", "name": "Толян", "level": 4 } }
{ "id": 2, "method": "chat.send",  "params": { "channel": "tavern", "text": "Здарова" } }
// сервер → клиент: ответ на каждый запрос…
{ "id": 2, "ok": true, "result": null }
{ "id": 3, "ok": false, "reason": "Нет прав" }
// …и события без запроса
{ "event": "chat.message", "data": { "id": "m_…", "channel": "tavern", "text": "Здарова", … } }
{ "event": "guild.updated", "data": { …Guild… } }     // или null — ты выбыл
{ "event": "guild.ladder", "data": [ …Guild[]… ] }
{ "event": "me", "data": { "id": "u_…", "name": "Толян", "role": "moderator", "guildId": null } }
```

Полный список методов с типами — `Methods` в `combat/src/net/protocol.ts`. До `auth.hello` любой запрос
получает «Сначала войди». Пинг каждые 30 с, молчащие соединения закрываются.

## Устройство

```
src/index.ts    запуск: переменные окружения, файл состояния, сигналы
src/server.ts   транспорт: HTTP + WebSocket, кто на связи, кому слать события
src/rpc.ts      имя метода → вызов ядра от имени вошедшего
src/core.ts     ядро без сети: все правила и проверки (GameCore)
src/store.ts    состояние и запись в JSON (fileStore / memoryStore для тестов)
```

Тесты: `npm test` — ядро (вход, роли, чат, модерация, гильдии), сервер по сети и клиентский адаптер
против настоящего сервера. `npm run typecheck` — tsc.

## Чего нет (пока)

- Хостинга: сервер запускается только локально. Для публики нужен VPS или Fly/Railway/Render
  с одним процессом и постоянным диском под `data/state.json`; перед телефоном — `wss://` (TLS).
- Кошелька: кредиты за основание гильдии, взносы и стол списывает телефон, сервер верит на слово.
  Слава гильдии от боёв тоже не считается (боёв на сервере нет). Это появится с PvP-сервером.
- Экраны чата и гильдий в игре пока зовут стор напрямую; `getBackend()` из `combat/src/net/index.ts`
  готов, их переключение на него — следующий шаг.
